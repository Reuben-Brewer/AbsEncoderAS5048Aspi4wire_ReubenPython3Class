AbsEncoderAS5048Aspi4wire_ReubenPython3Class

Code to read angles from the Absolute Magnetic Rotary Encoder AMS AS5048A over 4-wire-SPI in Windows (via the FTDI USB to MPSSE Serial Cable), Raspberry Pi 4B (connected directly to its pins), or Teensy 3.2/4.1 (connected to a computer via an FTDI TTL-232RG-VREG3V3-WE USBtoSerial cable).

Please see details for each OS within the following documents:
